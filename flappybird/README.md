# 像素鸟 Flappy Bird

单文件 H5 像素鸟游戏，使用原版 Flappy Bird 素材（贴图 + 音效），还原原版 288×512 分辨率与手感参数。
内置**玩家操作记录系统**与**从玩家录制提炼的 AI 演示**。

## 玩

直接双击打开 `flappy.html` 即可（素材已 base64 内嵌，无需服务器、无需联网）。

- 点击 / 空格 / ↑ / W：拍翅
- C（准备界面）：切换鸟颜色（黄/蓝/红）
- A 或画面右上角按钮：开关 AI 演示（开关状态持久化，刷新后延续）
- 画面右上角按钮：清除 AI 最高分 / 音效开关（状态持久化）
- 最高分保存在浏览器 localStorage

## 带记录系统运行（推荐）

```
node server.js        # 打开 http://127.0.0.1:8791
```

服务器在静态服务之外接收游戏上传的操作记录，每局一个文件：`recordings/run-时间戳-scoreN.json`。
（服务器不可用时记录自动兜底存 localStorage，不会丢。）

### 记录内容（只在玩家按键瞬间记录）

每次按键记录按键前一刻的局面：鸟位置 `by`、速度 `bv`、到下一柱距离 `dx`、
缺口上沿 `gapY`、缺口高度 `gapH`、鸟中心相对缺口中心偏差 `dy`、柱间距 `spacing`、当时分数；
死亡时补记死因（`ground`/`pipe`）与撞击柱的缺口偏差 `dyHit`。

## AI 演示（策略提炼自玩家录制，非凭空规则）

对 `recordings/` 中玩家按键统计提炼出两条规则 + 一条节奏约束，全部写进 `policyFlap()`：

| 策略 | 录制依据 | 实现 |
|---|---|---|
| 爬升连拍 | 低于缺口中心 55px 时以 ~13 帧间隔连拍 | `dy > 55` → 每 13 帧拍一次 |
| 中线以下补拍 | 单次拍翅固定上升 54px，判定安全区 \|dy\|≤41 | `dy ≥ 18` 且下落时补拍，波峰 dy≈-36 不顶沿 |
| 按键节奏 | 玩家两次按键最短间隔 10 帧 | 全局冷却 10 帧，绝不逐帧按键 |

关键前提：`situation()` 把**正在穿过的管道**（鸟尾未出管口）作为决策对象——
早期版本按鸟前端切换目标管，导致 AI 在管内按下一根管做决策而撞上当前管上沿（曾占死因 13/14）。

AI 自打分实时刷新并持久化（localStorage `flappy_ai_best`，可用"清除 AI 最高分"按钮归零）。
AI 的对局同样上传记录文件（文件名含 `ai-`，内容含 `isAI: true`）供分析。
实测（静音离线）：5 局 × 30000 帧零死亡（每局 352 分管道封顶）；
操作历史与玩家高度一致——按键间隔中位 30 帧、按键时速度中位 +6.5、巡航补拍 dy≈20。

## 文件

| 文件 | 说明 |
|---|---|
| `flappy.html` | 最终成品（单文件，素材已内嵌） |
| `game.template.html` | 游戏源码模板（含 `@@占位符@@`） |
| `build.js` | 构建脚本：`node build.js` 把 `assets/` 内嵌生成 `flappy.html` |
| `server.js` | 本地服务器：静态服务 + `POST /record` 存 `recordings/` |
| `recordings/` | 玩家操作记录 JSON（本地数据，不入库） |
| `assets/` | 原版素材：26 张贴图 + 5 个 ogg 音效 + LICENSE |

## 玩法参数（原版手感）

重力 0.45、拍翅 -7、终端速度 10、管道速度 2px/帧、间隙 100px、间距 170px；
撞击判定框内缩 (4,3) 同原版宽容度；每过 4 分管道切换昼夜；
撞击白闪 + 坠落动画；结算面板含 SCORE/BEST 与奖牌（10/20/30/40 分对应铜/银/金/白金）。
